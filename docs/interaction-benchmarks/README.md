# Admin 交互原型资产目录

本目录仅存用户实际授权制作的可交互验证成果；原型不是业务/API 权威，不要求固定六模块、四套主题、特定工具栏、统一目录页面结构或五条验收剧本。工作方式见 [原型与 AI 开发工作流](../development/frontend/interaction-benchmark-workflow.md)，最低质量见 [产物规范](../development/frontend/interaction-benchmark-spec.md)。

制作原型时优先使用合成数据、明确状态变化和可复现的负向/恢复用例。交付时给出可操作的体验说明、文件版本和未验证项。辅助控制与正式界面分离，原型不能伪造 UI 签收、安全或浏览器通过状态，也不能反向新增后端功能。

**验证状态**：历史 Chrome / Build 记录不作为本版证据。本版 HTML 已在本地 Chrome 实测主要交互与多视口布局；屏幕阅读器、实际 Supabase / RPC / RLS / Edge / R2 等仍未完成真实验收。

## 当前可运行原型（2026-10-24）

- **[AisenCore MVP 交互测试实验室](./aisencore-mvp-interaction-lab.html)**：单文件、无需安装依赖，直接用 Chrome / Edge 打开。包含 **15 类交互路由、31 项场景卡片（28 项模型检查，3 项需人工或真实环境核验）**；全局 11 个入口、单产品 6 个入口，共享用户与审计页但有不同语义。
- 功能路线：**全平台** → 平台总览、**产品管理**、全局用户、平台安全与审计；**单产品** → 当前产品概览、用户管理（含成员管理）、Pro 授权、发码、**反馈管理**、产品审计；公众邮箱注册/模拟登录、身份确认、加入/退出/重加入、兑换和资格推导；独立 AisenLens 合成 JSON 备份；管理员 AAL2、封禁、最后管理员保护、审计及故障注入。
- 体验入口：默认演示管理员为合成 AAL2，用户为「林沐」。演示登录密码为 `demo1234`；演示 TOTP 测试码为 `123456`；公开兑换 Fixture 为 `LENS-DEMO-2026`。**所有值仅用于该 HTML 的本地模拟，不是实际认证信息。**
- 完整流程建议：进入全平台「全功能测试」选择五条交互剧本之一；发码依次经历「填写 → 参数核对 → 确认 → 首次明文」，UNKNOWN 分别验证已创建批次撤销与未创建批次按原键重放。重置按钮仅重置本地内存模拟。
- **严格边界**：原型未接入 Supabase Auth/PostgreSQL/RLS/RPC/Edge/R2、SMTP 或支付通道；模型 PASS 不代表后端安全、并发、读屏无障碍或正式发布许可。页面刷新恢复初始合成数据，**请勿输入真实用户、密码或兑换码资料**。

## 视觉与交互迭代 · V2

- 自包含离线设计：深海蓝侧边导航、柔和背景、青柠色重点操作、紫色交互控件；统一首页主视觉、功能卡片、表格、表单、危险确认、移动端导航和 24 项测试卡片；无远程字体、图片或 JS 依赖。
- **快速跳转**：点击顶栏搜索图标，或按 `Ctrl+K` / `⌘K`；输入「兑换码」「安全」「产品」等关键词，方向键选择，`Enter` 跳转，`Esc` 关闭。键盘可使用“跳至主内容”链接，动态表单标签与提示有唯一关联。
- 本地 Chrome 回归覆盖 14 个任务入口、21 项模型自检、发码与安全恢复、本人重复兑换、快捷搜索，以及 320/390/768/1024/1600px 宽度的页面级溢出检查。**这是模拟原型与浏览器烟测，不是 3 项人工或真实服务测试的 PASS。**

## 交互优化 · V3（参考旧版 MVP-gemini 的有效设计）

本轮保留 V2 品牌视觉，不恢复旧版 `plans.features/limits`、Free 默认指针、套餐克隆或合并配额。所有新增流程仍为纯前端合成演示，数据不跨刷新保存。

- **用户 360° 诊断**：在用户目录点击“查看公共详情”，按产品切换，显示公共身份 → 产品状态 → 成员状态 → 当前 Pro 四段判断事实；同屏关联所选产品的成员状态、此次会话内状态转移、Pro Grant 和核销记录。管理员不能代用户调用本人 `CheckAccess`，诊断不访问任何 SaaS 私有资源。
- **兑换码运营中心**：切换“发行批次 / 单码安全检索 / 核销记录”，从批次跳转关联单码，按批次过滤及撤销未用完的批次；只显示安全元数据，历史明文不可重新下载。
- **发行前核对**：填写发行参数 → 显示产品、期限、数量、每码上限、到期及幂等键 → 单独确认发行。返回编辑仍保留表单原参数；真实发行只允许首次成功响应查看本次明文。
- **UNKNOWN 两分支**：模拟“已落库但明文丢失”需核查原批次并单独撤销；模拟“可信核查确认未落库”可使用原 `request_id` 与原参数显式重放；未完成处置时不允许新发码，查询本身不会发码。这些只模拟服务端可信事实，不表示真实网络或跨刷新恢复。
- **Pro 授权**：三种可选择模式（按天顺延、指定窗口、显式永久），实时展示以合成记录推导的期限预估；永久模式必须勾选确认。预估并非可信服务器事务结果。
- **引导式操作剧本**：在测试实验室开始四条跨模块旅程：用户故障诊断、兑换码生命周期、UNKNOWN 两分支、Pro 与范围边界。步骤用于学习与手动核对，不会自动改变模型 PASS / NOT RUN。
- **本轮 Chrome 烟测**：14/14 页面可访问；用户从 `suspended` 恢复到 `left`、批次 → 单码、发码预览、UNKNOWN 两分支、引导剧本及永久授权勾选均由浏览器交互检查。21 项模型断言仍为 PASS，3 项真实/人工环境测试仍为 NOT RUN，320～1600px 已检无页面级横向溢出，未出现 JS 异常。

**仍待独立验证**：真正的 PostgreSQL 原子发码与幂等、受保护管理 RPC / RLS / MFA、并发冲突、真实服务端 UNKNOWN 查询与会话重建、实际 SMTP、屏幕阅读器与完整 WCAG 审核，以及正式 React-admin 视觉与工程验收。

## 反馈管理 · V4

- **新页面：Admin → 反馈管理**。采用双栏「反馈收件箱 / 选中工单详情」布局，显示全量、待受理、处理中、已解决/关闭指标；可按顶部产品范围，以及标题、反馈编号、正文、用户邮箱、状态、优先级联合筛选。
- **真实可操作的前端处理流**：查看原始用户描述与产品信息、分配合成受理人、调整优先级、选择允许的状态流转（新反馈 → 分诊 → 处理中 → 待补充/已解决 → 关闭；支持重开）、写入必须填写的内部处理备注、单独编写给用户的公开答复、查看处理时间线。待用户补充或已解决前须存在公开答复。所有变更同步更新列表指标；全局审计只记录处理元数据，不复制备注原文。
- **用户提交端**：在「注册与账号」底部的「用户反馈」模块由当前已验证、未封禁的模拟身份创建反馈，可指定产品、类型、标题及描述。该身份只能在页面看到**自己的工单标题、处理状态、时间与明确发布的公开答复**；不能读到其他用户反馈或管理员的内部备注。提交只是内存操作，不发送真正的邮件、通知或工单。
- **测试剧本**：全功能测试实验室新增「从反馈到处理结果」引导；增加 3 项模型检查（本人信息隔离、允许的状态路径、AAL1 管理员入口拦截）。目前总计 **15 个任务页面、27 项测试卡（24 项模型检查 + 3 项人工/真实服务验证）**。
- **已执行 Chrome 操作检查**：公众提交后收件箱立即增加记录；管理员成功分类、设优先级、指定责任人并记录内部备注和公开答复；用户仅看到本人的公开答复，看不到他人记录或内部备注，未验证身份不可提交；多条件搜索、产品范围切换正常。15 个页面均可导航，24/24 项模型检查通过，3 项真实/人工验收保持 NOT RUN；本次操作未观察到 JS 异常。

**边界说明**：反馈模块只补当前 MVP 交互候选，**不批准或创建正式 Supabase 数据表、RPC、客服角色或发信接口**。所有内容都是合成示例，刷新会重置；对真实用户的权限隔离、RLS、邮件发送、工单服务端状态机、文件附件及数据保存策略仍需另行设计与验证。

## 全平台 / 单产品工作空间重构 · V5（2026-10-24）

**实施计划**：见 [详细计划与验收矩阵](./workspace-scope-refactor-plan.md)。当前 Demo 已按照已批准的 Core 业务边界重排管理体验；此变更只是前端模拟工作空间上下文，不是新建租户 RBAC 或正式后端权限。

- **全平台控制台**：侧边栏统一显示「全平台控制台」，进入后导航仅包含平台总览、产品管理、全局公共用户、平台安全、全局审计；注册或停用产品、平台账号封禁、管理员资格等真正的平台治理操作保留在这里。全局首页以可追溯的合成跨产品指标和单产品入口为主，不直接显示产品发码或直授表单。
- **单产品运营空间**：在全局产品卡片/产品目录中点击「进入管理」，或用侧边栏管理空间切换器进入 AisenLens / AisenNote 等产品。产品视角使用独立品牌标题、产品概览和独立的用户与成员、Pro 授权、兑换码、反馈、当前产品审计导航，不出现「产品管理」等全局菜单。
- **强制业务操作范围**：Pro 直授与兑换码发行的产品字段变为由当前工作空间绑定的只读标识；管理员提交仍经前端模拟范围校验，不能用跨产品隐藏字段替换目标。产品内成员暂停/恢复、授权撤销、码撤销、批次处理和反馈保存均核验实体的产品归属；平台产品治理、账号封禁、管理员资格写入只能在全局。
- **公共身份与产品诊断**：全局用户只读浏览账号和必要的跨产品关系摘要，可主动进入相应产品；产品用户 360° 的成员、授权、核销和诊断只属于当前产品，隐藏原来的跨产品诊断切换卡片。产品审计隔离其他产品及平台治理事件。
- **工作空间切换**：切换产品清空用户选择、搜索、筛选、临时批次预览等上下文；UNKNOWN 请求恢复未完成时不允许跨空间离开；首次明文离开需单独确认不可恢复；未保存参数、反馈备注草稿和同页面跳转均有离开确认。取消切换时保持原产品选择。命令搜索只列当前管理空间导航。
- **测试实验室**：公开注册、模拟登录、本人兑换及 AisenLens 备份仍是独立测试流程，置于全局的「独立测试区」，不混入某个产品的管理员菜单。原有 27 项测试卡继续保留，并增加 3 项工作空间测试：导航隔离、产品反馈隔离和表单固定目标。

**V5 浏览器验证**：全局 11 个导航入口和产品 7 个导航入口均可访问（公共路由去重后 16 类），工作空间切换、全局/产品用户诊断、产品固定发码与授权、反馈范围、UNKNOWN 切换阻止、未保存草稿确认及取消恢复均已实测。30 项测试卡为 **27 PASS 模型断言、3 NOT RUN 真实/人工测试、0 FAIL**；320/390/768/1024/1600px 检查未出现页面级横向溢出，当前 Chrome 回归未出现 JS 运行异常。

**与正式后端的区别**：工作空间选择器与前端守卫只是帮助明确管理上下文，不是可信权限边界。真实管理员资格、AAL2、RLS 与每次写入的受保护 RPC/事务仍必须独立实现与验证。历史参考目录 `参考/` 已于 2026-10-24 从项目移除，当前请以 V6 自包含 Demo 为准。

## 导航减法 · V6（2026-10-24）

- **合并成员管理**：删除单产品「成员管理」一级导航与冗余的独立成员列表，将产品导航中的「用户与成员」统一命名为「用户管理」。该页面现在包括按 `全部 / 正常 / 已暂停 / 已退出` 筛选成员、人数统计、用户/邮箱/成员 ID 搜索、列表快捷暂停/恢复、以及现有用户 360° 的成员事件、Pro、核销详情。全局「全局用户」仍独立且只读。
- **工作空间下拉简化**：移除侧边栏原来的 `MANAGEMENT SPACE` 大卡片、标题、副说明和强调配色，改成品牌下方**单行 42px 原生下拉框**（全平台控制台 / 当前及其他 SaaS）。顶部重复的 PRODUCT/GLOBAL 范围徽标与返回按钮不再常驻；品牌名称、面包屑和菜单已足以表明空间。
- **既有安全行为保留**：当前产品内暂停/恢复仍由带作用域验证的操作确认触发，`left → suspended → left` 不会意外重新加入；切换产品时仍保留草稿确认、一次性码保护和 UNKNOWN 恢复阻断。菜单删除不影响公共成员状态模型或服务端契约。
- **新增模型断言**：X25 确认不同成员筛选与列表操作在单一用户管理页可用，且不出现独立成员菜单。总计 **15 类交互路由、31 项场景卡（28 模型 + 3 人工/真实）**，产品空间只保留 **6 个**一级导航入口，全局仍是 **11 个**。
- **Chrome 实测**：当前工作空间下拉（全局与产品）均为 42px；已暂停成员的快捷恢复、从 `left` 再暂停及恢复、用户诊断事件展示、切换 AisenNote 后成员隔离、31 项场景检查 **28 PASS / 0 FAIL / 3 NOT RUN**。在 320、390、768、1024、1600px 测试宽度均无页面级横向溢出；检查过程中无 JS 运行异常。

本轮仍是离线 HTML Demo；不改变正式 AisenCore Auth/MFA/RLS/RPC、产品业务功能边界，不认为模型自检等同生产安全验收。

该原型仅作为当前可操作候选。React-admin 正式工程和真实服务测试仍须按当前需求及独立授权推进；旧历史测试记录不因新文件存在而自动变为通过。
