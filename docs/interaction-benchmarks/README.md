# Admin 交互原型资产目录

本目录仅存用户实际授权制作的可交互验证成果；原型不是业务/API 权威，不要求固定六模块、四套主题、特定工具栏、统一目录页面结构或五条验收剧本。工作方式见 [原型与 AI 开发工作流](../development/frontend/interaction-benchmark-workflow.md)，最低质量见 [产物规范](../development/frontend/interaction-benchmark-spec.md)。

制作原型时优先使用合成数据、明确状态变化和可复现的负向/恢复用例。交付时给出可操作的体验说明、文件版本和未验证项。辅助控制与正式界面分离，原型不能伪造 UI 签收、安全或浏览器通过状态，也不能反向新增后端功能。

**当前状态**：本目录内没有已确认可复现的全景 UI-G0A HTML；历史 Plans 曾引用的 `admin-codes-unknown/MVP-codex.html` 当前工作区不存在，相关 Chrome/渲染数字只是历史记录，不能当成当前可运行产物。原型签收与真实开发、运行验收分别由用户明确决定。
