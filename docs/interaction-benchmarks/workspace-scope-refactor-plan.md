# AisenCore MVP · 全局 / 单产品工作空间解耦实施计划

> 日期：2026-10-24；状态：当前 Demo 交互改造；范围仅 `docs/interaction-benchmarks/aisencore-mvp-interaction-lab.html` 及其说明、验收。原型不批准后端迁移 / RPC / RBAC。
>
> 用户设计目标：全局易辨认，主要观察且承接平台治理；单产品像独立的运营管理台，内部流程不牵涉其他产品。公共 AisenCore 事实不等于独立 SaaS 私有业务权限。

## 设计决策

1. 将传统「全部产品筛选器」重构为明确的**全平台 / 具体产品**工作空间切换。工作空间是产品业务操作的固定上下文，不等于授权凭证。
2. **全平台**包含平台总览、**产品管理**、全局账号目录、安全治理、全局审计，以及隔离于正常管理导航的演示测试实验室。允许真正的平台写操作（产品注册/暂停、平台级账号封禁、管理员名册）；产品发码、成员暂停、Pro 直授、反馈受理不得从全局直接写入。
3. **产品空间**包含该产品概览、用户/成员、Pro 授权、兑换码、反馈、该产品审计；不出现全局产品目录及其他产品的运营对象。任何产品业务写入只能指向工作空间的目标产品。
4. 模拟公开用户旅程放在**全局实验室**辅助区域（它是测试环境，不属于某个 Admin 产品运营导航）。公众用户的提交目标仍由公开用户自己选定。
5. 全局进入产品可直接深链到目标业务页面，产品切换重置目标对象和筛选，但不能静默丢弃未保存表单、一次性明文或未解决的 UNKNOWN。
6. 全局查询允许必要的公共事实聚合，不能因全局身份而读取任何独立 SaaS 私有项目或文件。正式管理权限仍由当前 AAL2、管理员资格、RLS/RPC 持续执行；不加新角色引擎。

## 分阶段任务及验收

| 阶段 | 工作 | 可观察完成标准 |
| --- | --- | --- |
| P0-A / 架构 | 工作空间 context、两套导航、切换器、保护性路由 | 全局/产品显示名称明显不同；非法跨空间路由被拒绝；产品页面无法混入全局菜单 |

## 关键场景

- 全局进入 AisenLens → 在兑换码创建预览中无需再次选产品 → 确认展示 **AisenLens** → 切换到 AisenNote 的入口要求处理草稿或秘密。
- 全局平台用户目录展示公共账号与跨产品关联数量；不能直接撤销 AisenNote 的 Pro。进入 AisenNote 详情后，仅显示它自己的成员/Grant/反馈。
- 产品 A 反馈选中后进入产品 B，必须清除旧工单选中，不能通过持有旧 ID 提交 B 的上下文。
- 在产品 A 中 UNKNOWN 未解决时切换全局或其他产品应被阻止；仍可执行核查、撤销或按原 request_id 重放；不得自动重复发码。
- AAL1 无法读取任何 Admin 管理资源；当前操作范围选择不能充当可信后端鉴权依据。

## 保留与限制

保留 V4 的视觉品牌、反馈公开答复与内部备注隔离、Grant 时间资格派生、Free 不落库、兑换码首次明文、双分支 UNKNOWN、成员 `left→suspended→left`、5 条引导剧本、现有测试实验室。真实 PostgreSQL、Auth、MFA、RLS、RPC、Edge、R2、SMTP、读屏和正式 React-admin 验收仍未执行。

## 执行与验证结果（2026-10-24）

- 当前 HTML 实施完成；保留 V4 合成反馈/Pro/兑换码等业务交互，未新增数据库、RPC 或服务权限。
- Chrome CDP 验证全平台 11 个导航入口、单产品 7 个入口；跨产品运行时状态隔离、UNKNOWN 阻止切换、未保存草稿确认/取消行为通过。
- HTML 自检共 30 项：27 项本地模型 PASS，3 项真实环境/人工 NOT RUN，0 FAIL。
- 浏览器测试 320/390/768/1024/1600px 页面级横向溢出检查通过，JS runtime exceptions 为 0。
- 风险仍在：真实 Supabase 权限、服务器事务、并发、深链重载、屏幕阅读器及正式 React-admin 工程尚未验收；Demo 中工作空间前端守卫不能作为后端授权证明。

**版本控制**：仅工作区本地变更；未经要求不提交、推送或修改旧版参考 Demo。
