# 用户反馈 V3：轻量管理、四队列与简洁详情

> 2026-10-26。V3 是现有 V2 基础上的增量改造，不代表云端上线授权。旧数据、旧事件与已上传的 R2 对象不得重置或丢弃。

## 目标

- 四个并列队列：收件箱、处理工作台、已归档、回收站；删除后按原位置恢复。
- 收件箱提前设置优先级、星标、标签和内部备注，进入工作台时保留全部整理结果。
- 用户单向提交；Admin 不再设置五态、不指派负责人、不回复提交者；服务端记录实际操作人。
- 同一行筛选优先级、星标、已有标签多选（OR）及 ZIP。标签由受保护的全量 SQL 字典提供。
- 有图片时详情左右双栏、无图正文通栏，历史按需弹窗。

## 安全与业务规则

| 动作 | 数据库规则 |
|---|---|
| 收件箱标记 | admin_feedback_v3(save) 保存优先级、星标、标签、私有备注；使用 expected_version |
| 加入工作台 | admin_feedback_v3(triage) 单事务落标记、私有备注、队列阶段与审计 |
| 归档 | workbench → archived；旧接口不可从 inbox 归档 |
| 删除 | inbox 或 workbench 软删除，并记录 deleted_from |
| 恢复 | trashed → deleted_from，不丢失优先级、标签、备注 |
| 重新处理 | archived → workbench |
| 最近处理人 | 有效 V3 写入记录 last_handled_by，事件记录 actor_user_id |
| 标签词典 | admin_feedback_tags(product_id?)，Admin 校验，服务端 distinct |
| 旧记录 | 保留五态、负责人、公开回复历史列与旧事件读取，新界面不再编辑 |
| ZIP | AAL2/管理员校验/敏感选项保持；标签多选与页面使用一致的 OR 筛选 |

继续保留 AAL2、NOLOGIN executor、RLS、版本锁、审计和私有 R2 访问控制。

## 核心验收

1. 收件箱保存多标签、星标、优先级、备注，原子进入工作台。
2. 收件箱与工作台删除后各回到原队列；归档只从工作台发生。
3. 并发版本冲突不静默覆盖；审计中的真实操作者和版本号一致。
4. 标签字典包含所有页，并按产品过滤，无跨产品泄漏。
5. 标签 OR 多选的页面结果与 ZIP 结果一致，敏感选项默认关闭。
6. 0、1、2 张图片预览固定尺寸、无布局跳动；高分辨率原图按需授权加载。
7. 1440/1024/768/390/320 视口无整页横向溢出或居中窄岛。
8. 真实 TOTP AAL2、管理员撤权、R2 私图、ZIP 与全站回归通过。

禁止以“编译通过”或“前端能点”替代图片链路及人工验收。
