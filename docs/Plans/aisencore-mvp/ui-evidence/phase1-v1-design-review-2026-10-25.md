# AisenCore Admin V1｜八维视觉迭代审查（2026-10-25）

> 审查对象：正式管理概览 `Dashboard.tsx`、共享 `theme.ts` 与 `App.tsx` 顶栏/侧栏。身份与业务采用本地真实 GoTrue AAL2 和合成 QA 数据；未连接 AisenLens 或线上环境。**这是工程自审，不是所有者审美签收，也不是任何设计奖项的结果。**

## 评审基准与方向

参考 Awwwards、Webby Awards、FWA 作品对鲜明视觉概念、编辑式文字、内容节奏、克制动画、操作反馈和性能的要求；只借鉴品质标准，不复制获奖作品的画面、商标或特效。Admin 的主要目标仍是快速完成有权限、有审计的真实业务操作，不使用干扰数据阅读的巨幅视频、重 3D 和无限滚动叙事。

**本轮视觉概念**：安静的业务控制室。左侧暖纸色真实经营数字和大字阶；右侧深松绿「信号轨道」抽象品牌面板；紫色仅用于关键品牌强调，成功、错误等状态继续使用独立语义色。全部数据均由原有受保护查询提供，不添加虚构增长率。

## 自审循环记录

1. 初始源码审计：旧版首页有两个解释性主标题、相近密度的卡片与普通圆形装饰，视线缺乏清楚优先级 → 重排内容、统一主题与标识。
2. 第一次正式预览 Chrome：KPI 链接 `aria-label` 覆盖了可见标签，axe 报 `label-content-name-mismatch` 1个规则/4元素 → 删除覆盖名称，重新构建并运行全套 Chrome，通过。
3. 1440 与 320 真实截图复看：320 英文铭牌换行、主/次按钮文字窄屏断行、深色图形点/角标碰撞 → 移动端缩短铭牌、按钮纵向全宽、角标隐藏，装饰点移至右侧。
4. 第二次 320 截图复看：按钮单行、铭牌单行、装饰与正文分离；新增 320/390 Chrome 几何断言和完整回归 **exit 0**。没有观察到新的已确认 P0 视觉错位，但仍有未执行的人工/设备测试。
