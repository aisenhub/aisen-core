## 1. 目标与发布边界

把已经本地交付的Core/Admin/Lens范围放到明确获授权的测试/预发环境，证明真实域名/HTTPS、Auth/SMTP/回调/JWT、PostgREST/RLS、Edge/私有R2、跨服务一致性、运维恢复和实际浏览器可用；再按独立批准发布。

本地PASS不推断真实R2/公网CORS/邮件可达。当前排除的AI Pro/去水印/第二项目门槛、支付/爱发电、桌面/移动等若无后续独立交付，不能在上线说明或UI假称已支持。注销具体渠道需在公开相应能力前明确，此前无可成功申请按钮，不建自动删号接口。

## 3. 顺序与交付物

| 步骤 | 允许范围内的动作 | 实际准出 |
| --- | --- | --- |
| 3-01 配置与风险审阅 | 列候选/权限/密钥分类、线上与本地差异、资源/费用、数据/回退影响 | 具体可审阅清单及授权，未获准不依赖性操作 |
| 3-02 测试/预发配置 | 配Core Auth/DB/Edge、私有R2、SMTP、域名/回调、Admin/Lens公开变量；应用当前唯一schema而不做旧兼容 | 精确环境映射、秘密不下发、公知测试管理员/开发密钥未上线；不清空现有云库 |
| 3-03 受控部署 | 按实际部署平台现有机制部署签收构建，核对SPA路由/静态资源/Edge加载/允许origin | 实际部署ID/版本/健康检查和最小真实业务切片，不能只看构建成功 |
| 3-04 云端全链路 | 注册/真实邮件/恢复/刷新、成员/Grant/兑换、0/1/2图/ZIP、模板备份/恢复/删除 | 真实部署端HTTP/JWT/DB/R2/浏览器证据，本地替身证据不混用 |
| 3-05 故障与运维 | R2条件写/限权、对象与DB单侧失败/重放/保护期清理、管理员失因子、恢复演练/监测；按下述合同演练人工注销 | 可执行恢复与告警，已引用对象不误删，旧token/URL窗口及人工注销中断续办有证据 |
| 3-06 非功能/秘密复核 | 公网网络/并发/查询/浏览器UI性能、键盘/响应式、构建与日志秘密扫描 | 代表规模与实际预算、无严重回归，生产配置/访问控制正确 |
| 3-07 发布报告 | 汇总范围、结果/风险、未测/排除项、回退/责任和公开文案 | 所有者对具体结果单独批准公开上线；部署测试许可不等于公开许可 |
| 3-08 批准后核验 | 按获准范围发布并做实际smoke，核对域名/候选/数据库/对象/告警 | 真实结果记录与运维交接；失败先控制受影响入口，按具体恢复计划处置 |

部署平台以项目真实配置和明确选择为准；不因可用插件就换托管平台、增加服务、自动建资源或触发计费。计划不创建自动化或后台监控任务。

3-05的人工注销按[账号生命周期验收合同](../../architecture/domains/platform-admin-and-account-lifecycle.md)执行：仅对获准隔离账号核验身份、限制访问、处理批准范围的反馈/备份及必要留存、最后处理Auth身份；核查残留对象、访问窗口与本机数据不变。注入对象清理或Auth处理失败，记录已完成/未完成步骤并验证安全继续。渠道/留存清单/责任未定或演练未通过均为公开上线阻塞，隐藏申请按钮不能替代验收；不新建自动注销接口，本计划不授权实际删除。

## 5. 失败、回退与最终交接

上线前先证明配置/数据恢复步骤可执行；有真实数据变更的操作保留所需快照/审计，未经明确授权不reset/删库/bucket。前端回退只能回到仍符合当前唯一API/schema的已验证构建，不能为回滚设计旧RPC别名/双格式兼容；不存在可用候选时停止相关公开入口并修复，不声称任意历史版本可安全回退。

提交部署/测试/公开上线分别记录实际授权与执行结果，Git推送也按明确许可执行。不能以某一步失败擅自扩展到生产或换资源绕过验证。

最终交接：已发布精确版本/部署ID、环境和责任表、安全API/操作说明、真实云证据、监测/对账/恢复步骤、未公开/后续业务范围、剩余决策及所有者批准。完成的施工计划按既有文档规范提炼证据和剩余TODO后收缩，不保留失效合同。
