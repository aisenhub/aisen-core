# 任务名称

- 状态：DRAFT
- 依据：链接 spec 中的需求/条款、审查问题编号或复现记录
- 范围：此次需要改变的行为与受影响模块
- 完成标准：本次覆盖的需求验收编号、用户可观察结果与验证方式

## 决定

记录当前问题、采用的最小方案、必要契约变化与尚待确认的决定。用户需求维护在 spec，体验选择维护在设计，已实现事实进入架构，尚未实施的技术施工方案留在此计划；相互链接，不重复抄写。

## 步骤

- [ ] 复现或编写失败行为测试。
- [ ] 实施修改并更新全部调用者。
- [ ] 执行相关检查，同步当前文档。
- [ ] 回写对应问题，转移剩余事项，清理过程文件。
