# 本地优先产品专项架构

> 状态：本地拉片数据与备份边界、首版在线会员校验原则及 Aisenlens 的部分 Free/Pro/恢复/断网体验已确认；具体白名单字段、额度和复核缓存仍待产品对接
> 适用：已确认首发的本地优先产品 **Aisenlens**，及以后同类型产品；不作为其他产品的强制架构。首批 R2 私有配置/文件备份已由用户确认必须支持，具体 API/元数据实施候选见[D2 接入设计](../../Plans/aisencore-mvp-d2-api-auth-aisenlens-implementation-design.md)；下述业务限制不因接入计划而变更。

## 数据与服务职责

| 内容 | 位置和数据流 |
| --- | --- |
| 视频、切片、关键帧、缓存 | 用户本地文件，不经运营方服务器 |
| 拉片项目、时间轴、分析结果、提示词 | 本地业务文件或数据库，具体格式由实际产品确定 |
| AI 密钥 | 用户设备本地保存，不进入备份文件或公共后台 |
| AI 分析 | 客户端按需直接访问第三方大模型，结果回到本地，平台不做代理 |
| 身份、产品级免费与付费权益 | 公共 Supabase 身份和权益能力 |
| 订阅支付 | 公共轻量计费能力 |
| 用户的设置和拉片模板 | 以本地配置为主；仅用户主动触发时备份 |
| 配置备份文件 | 客户端获得限定权限后直接上传/下载 Cloudflare R2，Supabase 不转发文件字节 |
| 备份清单 | 可存最少的用户关联、R2 对象标识与版本记录，具体字段待产品接入 |

第三方大模型会收到用户主动提交的分析输入；“不经过运营方服务器”不代表“不会发送给第三方模型”。

## 配置备份、恢复与分享

- 备份仅包含实际客户端允许迁移的设置和拉片模板文本，不包含视频、AI 结果或 API Key。
- 用户确认**不需要客户端端到端加密**，运营方可以读取配置明文；但传输仍应加密，备份仍是**用户私有数据**，其他用户不能直接访问。
- 配置直接上传/下载 R2，公共服务只处理必要的账号鉴权、授权和备份索引。具体上传/恢复协议以后按实际拉片项目设计。
- 私有备份**不得直接作为公开分享内容**。未来如果引入配置链接或模板广场，应由用户明确发布单独的可分享副本；是否建设分享功能本身仍未决定。
- **首发 Aisenlens 已决定**：只允许用户主动选择并由 Aisenlens 实际定义的非敏感**平台配置参数与允许的模板文本**进入白名单，任何其它字段一律不备份。用户从私有备份清单**手动选择版本 → 预览差异 → 明确确认后仅替换所选配置类别**；不能默认自动合并或无提示覆盖。字段 JSON schema、类别清单、备份数量和保留期限尚未确定。

## 本地产品成员边界

首次使用需要登录的公共账号能力（如会员在线校验或用户主动发起的私有备份）时，可信平台按需建立该产品成员；匿名免费本地功能不创建成员，也不因退出而失效。成员退出只停止新的受保护账号/云端服务操作，不清除本地视频、项目、AI 结果、密钥及配置。原有私有 R2 配置备份不因退出立即删除，具体保留与清理由产品政策决定。

退出后的 Pro 授权事实和有效期独立保留；重新加入必须明确触发，成员被暂停则只有可信管理员能解除。在线状态变化无法保证已离线的本地操作立即终止；具体运行中断时机仍按产品决定。详见[成员生命周期专项](../domains/membership-lifecycle.md)。

## 本地会员权益

- 公共平台提供权威的按产品权益；本地客户端负责允许或限制实际付费功能。
- **首版拉片 Pro 必须在线校验**：客户端启动时检查当前产品权益，并在软件运行期间根据本产品实际业务**合理复核**，例如用户开始某项高级拉片操作、使用受限功能或其他关键环节时。无需每次用户点击都联网，也不规定所有 SaaS 相同的复核频率。
- **首版不实现通用桌面离线 Pro 授权**，未来如有其他 SaaS 确实需要离线会员，可根据产品实际情况扩展。已经开始的操作遇到短暂断网如何处理、下一次复核失败后如何通知用户，应在拉片客户端对接时定规则，不默认可以长期断网保留 Pro。
- **首发 Aisenlens 已确定体验**：Free 保有可用的本地基础工作流；Pro 包含客户端直连第三方模型的 AI 分析（用户自带 API Key）、无水印视频导出及用户主动的云配置备份。Pro 在启动/关键操作复核，**已启动的纯本地任务**即使暂时断网也可完成；无法可信核验时不得启动新的受保护 Pro 操作。**最近成功复核 15 分钟以内可以短暂复用状态**只是用户同意评测的候选时长，不是已经测试/冻结的离线授权；新 R2 签名/云端受保护操作每次需要可信在线检查，不能共用本地缓存。
- **首版低请求量明确实现方向**：匿名 Free 打开/操作无需向 Supabase 请求 Auth/权益；Pro 采用启动/首次进入与关键操作前**按需**复核，重复 UI/同账号同产品并发请求合并，不在软件闲置时每 15 分钟固定轮询。Pro 校验可异步加载，**不能因此阻塞本地 Free 启动**。15 分钟仅为本地授权快照新鲜度待测候选且不得跨账号复用；已过授权自然到期点的缓存失效。**离线但缓存仍新鲜能否启动新纯本地 Pro 任务**仍须按 U11 单独冻结；云端上传/下载签名及 complete 由产品可信服务器每次重新校验，不信客户端快照。聚合功能快照仅是候选接口，见[专项方案](../../Plans/aisencore-mvp-auth-entitlement-mfa-efficiency-design.md)。
- 客户端应能区分本产品的 Free / Pro 功能，必要时实施使用次数或数量限制、备份配额限制和有效期判断；本地使用量如何可信地计数尚未决定。
- 普通免费本地功能不应仅因无网络就被无关禁用；需要调用云端大模型的分析功能则依赖模型服务可用性。掉线后 Pro 是否立即停止新操作、订阅到期/退款后的复核时效、多设备规则仍待确认。
- 本地软件无法保证绝对防破解；**首版执行已确认的在线校验原则**，具体通信协议和复核点后续按产品决定。离线凭据仅在未来出现真实需求时再考虑。
- **网页保存到本地的保护边界**：联网验证与合理复核能阻止正常客户端在没有有效权益时继续走标准 Pro 使用流程；但已下发给浏览器或桌面的完整本地代码可以被保存或修改，不能仅靠客户端校验保证不被复制。可在产品确有云端付费能力时，对关键云端请求做服务端授权；**不为了反复制把已确定留本地的拉片视频/AI 内容搬到平台云端**。

## 不做与待确认

- **不做**：平台中转视频、AI 输入/分析结果或密钥；强制云端保存用户拉片项目；自动公开私有备份；预先建设配置广场。
- **待确认的细节**：Pro 15 分钟缓存真实测试/撤权窗口、具体 AI/导出 feature key、备份字段和额度、版本数量/保留期限、本地文件路径、会员撤销与设备约束；**恢复流程已确认选择手动版本/差异预览/按类别替换，不再把覆盖还是合并整体写成待定**。未来是否分享模板仍未批准。
