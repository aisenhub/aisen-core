# 本地优先产品专项架构

> 状态：本地数据边界、完整分析模板备份、20 份及到期取回政策已确认；5 MiB 与最多 15 分钟本地权益快照为已采纳待实测参数。专属备份后端/双端仍未交付，当前仅文档同步。
> 适用：已确认首发的本地优先产品 **Aisenlens**，及以后同类型产品；不作为其他产品的强制架构。首批 R2 私有配置/文件备份已由用户确认必须支持，长期 API/元数据边界见[产品文件架构](../database/product-data-and-files.md)及[公共 API](../backend/api-contract-and-mvp-acceptance.md)；下述业务限制不因接入计划而变更。

## 数据与服务职责

| 内容 | 位置和数据流 |
| --- | --- |
| 视频、切片、关键帧、缓存 | 用户本地文件，不经运营方服务器 |
| 拉片项目、时间轴、分析结果、提示词 | 本地业务文件或数据库，具体格式由实际产品确定 |
| AI 密钥 | 用户设备本地保存，不进入备份文件或公共后台 |
| AI 分析 | 客户端按需直接访问第三方大模型，结果回到本地，平台不做代理 |
| 身份、产品级免费与付费权益 | 公共 Supabase 身份和权益能力 |
| 订阅支付 | 公共轻量计费能力 |
| 用户的设置和拉片模板 | 设置仅存本机；仅当前上下文完整已生效分析模板可主动备份 |
| Aisenlens 允许的非敏感小型配置 JSON | 客户端向受保护 Supabase Edge 上传 JSON，可信校验后写 Cloudflare R2 final；恢复时客户端经授权从 R2 直接下载 |
| 备份清单 | 可存最少的用户关联、R2 对象标识与版本记录，具体字段待产品接入 |

第三方大模型会收到用户主动提交的分析输入；“不经过运营方服务器”不代表“不会发送给第三方模型”。

## 配置备份、恢复与分享

- 备份仅包含当前上下文一套完整已生效分析模板及必要包元信息；界面/应用/AI 设置、结果参数、视频、项目、答案、AI 结果及凭据均不纳入。
- 用户确认**不需要客户端端到端加密**，运营方可以读取配置明文；但传输仍应加密，备份仍是**用户私有数据**，其他用户不能直接访问。
- **DEC-02 A 已批准**：Aisenlens 非敏感白名单 JSON 备份使用受保护 Edge 接收与校验并写 R2 final，数据库只保留必要的属主/版本/对象/预留和状态；云端备份或恢复的每一次新授权仍需在线复核，下载可以经短期授权从 R2 直取。大文件或其它产品私有文件仍可按客户端 R2 直传路径设计。
- 私有备份**不得直接作为公开分享内容**。未来如果引入配置链接或模板广场，应由用户明确发布单独的可分享副本；是否建设分享功能本身仍未决定。
- **AisenLens 备份与恢复**：项目库取个人模板，工作台取当前项目已保存模板，不枚举其他项目；手动选云版本、预览完整模板差异、确认后整体替换个人模板，不分类、不合并、不回写项目。20 份、已采纳待实测的 5 MiB、到期可取回/删除及正常服务不按年龄删旧，统一见[文件架构](../database/product-data-and-files.md)。

## 本地产品成员边界

首次使用需要登录的公共账号能力（如会员在线校验或用户主动发起的私有备份）时，可信平台按需建立该产品成员；匿名免费本地功能不创建成员，也不因退出而失效。成员退出只停止新的受保护账号/云端服务操作，不清除本地视频、项目、AI 结果、密钥及配置。原有私有 R2 配置备份不因退出立即删除，具体保留与清理由产品政策决定。

退出后的 Pro 授权事实和有效期独立保留；重新加入必须明确触发，成员被暂停则只有可信管理员能解除。在线状态变化无法保证已离线的本地操作立即终止；具体运行中断时机仍按产品决定。详见[成员生命周期专项](../domains/membership-lifecycle.md)。

## 本地会员权益

- 公共平台提供权威的按产品权益；本地客户端负责允许或限制实际付费功能。
- **首版拉片 Pro 必须在线校验**：客户端启动时检查当前产品权益，并在软件运行期间根据本产品实际业务**合理复核**，例如用户开始某项高级拉片操作、使用受限功能或其他关键环节时。无需每次用户点击都联网，也不规定所有 SaaS 相同的复核频率。
- **首版不实现通用桌面离线 Pro 许可证**；本地快照只按以下时效短暂复用，不授予长期离线使用权。
- **AisenLens 本地 Pro 时序**：最近成功核验暂按最多 15 分钟测试，在同环境/用户/产品、未自然到期且无已知撤权的快照内，短暂断网可开始新的纯本地 Pro 操作。新 AI 请求及云端操作必须在线核验；已经发出的 AI 请求/已经开始的本地导出可收尾，后续未发请求不得靠失效缓存继续。该窗口已采纳但未经完整实测，不是离线许可证。
- **低请求量**：匿名本地 Free 零非必要 Auth/RPC，不等待权益查询；启动/关键操作按需复核，同身份/产品并发去重，不固定每 15 分钟轮询。云端预留/最终确认/签名下载由可信端实时授权，客户端快照不构成云权限。
- 客户端应能区分本产品的 Free / Pro 功能，必要时实施使用次数或数量限制、备份配额限制和有效期判断；本地使用量如何可信地计数尚未决定。
- 普通免费本地功能不因断网失效；新 AI 请求还依赖第三方模型服务。本轮仅打通后端与账号相关界面，不启用 AI/去水印/第二项目门槛；允许必要登出/切号凭据及在途任务接线，不改 AI、Provider 或项目算法。
- 本地软件无法保证绝对防破解；**首版执行已确认的在线校验原则**，具体通信协议和复核点后续按产品决定。离线凭据仅在未来出现真实需求时再考虑。
- **网页保存到本地的保护边界**：联网验证与合理复核能阻止正常客户端在没有有效权益时继续走标准 Pro 使用流程；但已下发给浏览器或桌面的完整本地代码可以被保存或修改，不能仅靠客户端校验保证不被复制。可在产品确有云端付费能力时，对关键云端请求做服务端授权；**不为了反复制把已确定留本地的拉片视频/AI 内容搬到平台云端**。

## 不做与待确认

- **不做**：平台中转视频、AI 输入/分析结果或密钥；强制云端保存用户拉片项目；自动公开私有备份；预先建设配置广场。
- **待实施/实测**：当前模板格式全层白名单、5 MiB 载荷与接口、15 分钟快照/撤权时效、专属 RPC/Edge/配额和对象对账；不再把已确认的恢复方式、20 份及到期取回列为未决。注销渠道及停服政策上线前确定。
