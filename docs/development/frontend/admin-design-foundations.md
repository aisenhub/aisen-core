# Admin 设计基础｜规则消费指南（非第二套 Token）

> **唯一精确数值**：[Admin UI-G0 全局视觉权威](../../architecture/applications/admin-ui-design-system.md)；这里记录来源参考中的**通用方法和验证点**。正式字体/HEX/间距/主题尚待 UI-G0 真实高保真与用户签收，不能因本文发布而锁定。

## 语义色、表面和层次

- 先定义功能角色，再消费 MUI `palette`/自定义语义 Token：应用底色、普通内容、表格/输入、浮层、文字主次、交互焦点、成功/警告/危险。**不能页面内局部补色值**，也不因颜色相近创建无用途的别名。
- 结构分隔、表格弱分隔、真实输入边界、选中、焦点及错误各自有不同职责；不能为了“高级灰”把输入/焦点同时调淡。所有关键对比按**实际底色和状态**检查，不从 HEX 名称推断合格。
- Admin 首版浅色是候选；不从 AisenLens 继承默认深色、透明玻璃浮层/材质皮肤。普通数据、文字与表单优先可读实色；Popover/Dialog 按 MUI Portal/Layer 体系定位，避免任意 z-index 和每卡厚阴影。

## 字体、字号角色与混排

- 文字角色包括页面标题、区块/面板标题、表单 label、控件文字、正文、连续说明、caption、数据/UUID；**字号、字重、行高、字体回退一起定义和评审**。当前 UI-G0 候选为系统中英文字体栈及 24/20/18/14/12～13px 层次；具体数值只在 UI-G0 维护。
- **视觉角色与文档语义分开**：用适当 `h1/h2` 层级和 aria-label，不能靠增大字体取代语义；中文不要套西文全大写/异常 tracking；不会因英文变长机械缩字。
- Admin 必须检查简体中文、英文、混排、长邮箱、UUID、UTC 时间和数字列。数字对齐优先 `tabular-nums`，只对确需逐字符辨认的 ID/短码局部使用等宽字体；长值缩略展示要提供**合法授权下的完整复制/查看**。
- 输入/按钮高度应满足**字形 + 行高 + 边框 + padding 的最小值**；放大文字或多行内容允许容器自然长高，禁止全页 transform 缩放或固定高度裁掉错误提示。
- 中英文真实 fallback、浏览器字体失效、字重合成、200%/400% 缩放、320/375px 与真实宽表要在 UI-G0 设计审核及 UI-G3 浏览器分别取证。不可把单张字体样图当最终验证。

## 空间、密度与布局

- 使用 UI-G0 一个 `theme.spacing()` 基线/语义间距区分控件内、图文、字段、分组、页面留白；不要求每个像素建独立 token。
- Admin 首版**一个标准密度**，暂不额外引入 AisenLens 的紧凑/标准/舒适用户设置；如果未来产品确实要求变密度，必须**同时调整字号/行高、控件尺寸、表格行高、Portal/菜单和测量**，不能只改一个 padding。
- 宽表和日志允许局部滚动；先处理 `minWidth: 0`、容器收缩/网格最小值和换行，不准以 root `overflow-x:hidden` 掩盖缺陷。菜单/弹窗的 z-index、焦点和遮挡按一个 UI-G0 全局 Layout/层次实现。
- 动态视口/虚拟键盘/滚动与可操作区优先以真实设备和浏览器验证；不迷信 100vh 或单一响应式断点，避免浮动底栏挡住 MFA 按钮。

## 图标、形状与动效

- 同一动作使用同一图标语义/线宽/尺寸；Admin 优先选与 React-admin/MUI 已有组件兼容的单一图标家族，不因参考 AisenLens 使用 Lucide 就强制引入第二套。**装饰性图标没有信息价值就删除**，带文字图标避免辅助技术双读，仅图标按钮必须有可访问名称。
- 圆角/按钮/input/Dialog 与表格分隔由 UI-G0 的单一 Token 管，局部例外不能擅自改变外围对齐或业务行为。
- 动画按目的区分点击反馈、展开/关闭、任务状态；无真实进度就不用百分比；支持 `prefers-reduced-motion`，快速关闭/重开时不丢焦点或状态。Admin 不继承视频工作台专用动画。
